Zeck

Download zeck.zip

Install

  1. Unzip the file into a folder you will keep.
  2. Open chrome://extensions (type it into the address bar).
  3. Turn on Developer mode (top right).
  4. Click Load unpacked and select the unzipped folder.
  5. Done.

Zeck copies the text of one page element to your clipboard when you press a key combination. It runs only on psssbtyping.com, ignores typing in form fields, and sends no data anywhere.

Use: on psssbtyping.com, click outside the typing box and hold a + f + j + ; together to copy the passage. To change which element is copied, click the extension icon.

Selector: right-click the element and choose Inspect. Then right-click the highlighted node and choose Copy → Copy selector.

Why no one-click install? Chrome on Windows and Mac only installs extensions in one click from the Chrome Web Store, so a zip with Load unpacked is the way to go here.
