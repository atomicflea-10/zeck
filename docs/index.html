Zeck

A small Chrome extension. On one site you choose, pressing 2–6 keys you choose copies the text of one page element to your clipboard. It works only in Chrome and only on that site, it ignores typing in form fields, and it sends no data anywhere.

Download zeck.zip

Install

  1. Unzip the file into a folder you will keep. Chrome loads the extension from that folder.
  2. Open chrome://extensions (type it into the address bar).
  3. Turn on Developer mode (top right).
  4. Click Load unpacked and select the unzipped folder (the one that contains manifest.json).
  5. Done. On psssbtyping.com, click outside the typing box and hold a + f + j + ; together to copy the passage. To use a different site, click the extension icon.

To find a selector, right-click the element on the page and choose Inspect. Then right-click the highlighted node and choose Copy → Copy selector.

Why not a one-click install?

Chrome on Windows and Mac does not let websites install extensions directly. A .crx file downloaded from a website, including this one, will not install with one click. One-click install is only available through the Chrome Web Store or on company-managed computers. For everyone else, the zip with Load unpacked is the supported way to install.
